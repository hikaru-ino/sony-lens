# 🔍 Sony Lens

> ソニーグループの多角的な事業構造と最新の業績を、ファンと投資家の両方の視点から覗くためのレンズ。

![status](https://img.shields.io/badge/status-WIP-orange)
![license](https://img.shields.io/badge/license-MIT-blue)

## 📖 プロジェクト概要

**Sony Lens** は、ソニーグループ株式会社(証券コード:6758)の事業全貌と業績を、一つの画面から立体的に把握できる Web アプリケーションです。

ソニーはゲーム、音楽、映画、半導体(イメージセンサー)、金融、エレクトロニクスと **極めて広範な事業ポートフォリオ** を持つ企業ですが、その全体像を一目で理解できる場所はあまり多くありません。本プロジェクトはその課題を、データ可視化と情報集約によって解決します。

## 💡 なぜ作ったか

筆者は学生時代からソニー製品(PlayStation、ヘッドホン、カメラ)の長年のファンであり、同社の事業の広さに興味を持ってきました。一方で、ソニーが**どの事業でどれだけ稼いでいるのか**、**最近の業績はどうなっているのか**を、ファン目線で気軽に確認できるサイトは見当たりませんでした。

「推し企業を、もっと立体的に知りたい」——その気持ちを起点に、このサイトを作っています。

## ✨ 主な機能(予定)

### ファン視点
- **事業セグメント別の売上構成ビジュアライザ** — ゲーム、音楽、映画、半導体、エレクトロニクスなどの売上比率を円グラフで可視化
- **代表プロダクト・作品ギャラリー** — 各事業の象徴的なプロダクト・作品をカード形式で展示
- **ソニー製品ヒストリー年表** — ウォークマンから PS5、AIBO まで、歴代のソニープロダクトをインタラクティブな年表で表示

### 投資家視点
- **業績ダッシュボード** — 最新の四半期決算、売上・営業利益の推移
- **株価チャート** — 日次株価データを期間切り替え可能なチャートで表示
- **業績と製品のリンク** — 業績が伸びた時期にどんなヒット商品が出ていたかを横断的に確認

### 共通
- **最新ニュースフィード** — IR ニュース、新製品発表のタイムライン
- **「あなたが生まれた年のソニー」** — パーソナライズで生年を入力すると、その年の主要プロダクトを表示

## 🛠 技術スタック(予定)

| 領域 | 採用技術 | 採用理由 |
|---|---|---|
| フロントエンド | Next.js (App Router) + TypeScript | SSG/SSR を使い分けられ、SEO とパフォーマンスの両立がしやすい |
| スタイリング | Tailwind CSS | 高速にプロトタイピングしつつ、デザインの一貫性を保てる |
| データ可視化 | Recharts | React 親和性が高く、宣言的にチャートを組める |
| データソース | J-Quants API / Yahoo Finance / Wikipedia API | 公式・準公式の信頼できるソースを優先 |
| データ永続化 | SQLite(開発) / Supabase(本番) | 無料枠で運用でき、レート制限対策のキャッシュ層として活用 |
| ホスティング | Vercel | Next.js との相性が良く、無料枠で十分運用可能 |

## 🗂 データソース

- [ソニーグループ IR 情報](https://www.sony.com/ja/SonyInfo/IR/) — 決算短信、有価証券報告書
- [J-Quants API](https://jpx-jquants.com/) — 株価・財務データ(JPX 公式)
- [Wikipedia / Wikidata API](https://www.wikidata.org/) — 歴史的プロダクト情報
- [TMDB API](https://www.themoviedb.org/) — ソニーピクチャーズ作品情報(計画中)

## 🚀 セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/<your-username>/sony-lens.git
cd sony-lens

# 依存パッケージをインストール
npm install

# 環境変数を設定
cp .env.example .env.local
# .env.local を編集して必要な API キーを設定

# 開発サーバーを起動
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くとアプリが表示されます。

## 📁 ディレクトリ構成(予定)

```
sony-lens/
├── app/                  # Next.js App Router
│   ├── page.tsx          # トップページ(事業全貌ビジュアライザ)
│   ├── segments/         # 事業セグメント別ページ
│   ├── ir/               # 業績ダッシュボード
│   └── history/          # プロダクト年表
├── components/           # 再利用可能な UI コンポーネント
├── lib/                  # データ取得・整形ロジック
├── data/                 # 静的データ(プロダクト一覧など)
└── public/               # 画像・アイコン
```
