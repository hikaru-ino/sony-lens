# 🔍 Sony Lens

> ソニーグループの多角的な事業構造と最新の業績を、ファンと投資家の両方の視点から覗くためのレンズ。

![status](https://img.shields.io/badge/status-WIP-orange)
![license](https://img.shields.io/badge/license-MIT-blue)

## 📖 プロジェクト概要

**Sony Lens** は、ソニーグループ株式会社(証券コード:6758)の事業全貌と業績を、一つの画面から立体的に把握できる Web アプリケーションです。

ソニーはゲーム、音楽、映画、半導体(イメージセンサー)、金融、エレクトロニクスと **極めて広範な事業ポートフォリオ** を持つ企業ですが、その全体像を一目で理解できる場所はあまり多くありません。本プロジェクトはその課題を、データ可視化と情報集約によって解決します。

## 💡 なぜ作ったか

筆者は学生時代からソニー製品(PlayStation、ヘッドホン、カメラ)の長年のファンであり、同社の事業の広さに興味を持ってきました。一方で、ソニーが**どの事業でどれだけ稼いでいるのか**、**最近の業績はどうなっているのか**を、ファン目線で気軽に確認できるサイトは見当たりませんでした。

「推し企業を、もっと立体的に知りたい」——その気持ちを起点に、このサイトを作っています。

## ✨ 現在の主な機能

### ファン視点
- **代表プロダクト・作品マルキー** — PlayStation、α、BRAVIA、Sony Music などを事業横断で表示
- **事業セグメント詳細** — セグメントを選択すると、その事業の特徴と分析メモを表示

### 投資家視点
- **KPI ダッシュボード** — FY2024 の売上高、営業利益、参考株価、時価総額を表示
- **セグメント比較** — 売上、営業利益、営業利益率、売上シェアを切り替えて比較
- **自動要約インサイト** — 最大売上、最大利益、最高利益率、最高成長率のセグメントを自動表示
- **参考株価チャート** — 1M / 3M / 6M / 1Y の静的サンプルチャートを切り替え

### 共通
- **出典と注意書き** — Sony IR、IRBANK、EDINET への導線と投資助言ではない旨を明記
- **レスポンシブ対応** — モバイル向けのメニュー、レイアウト、縮小モーション設定に対応

## 🛠 技術スタック

| 領域 | 採用技術 | 採用理由 |
|---|---|---|
| フロントエンド | 静的 HTML / CSS / JavaScript | 依存なしで表示でき、プロトタイプの共有がしやすい |
| スタイリング | CSS カスタムプロパティ | 単一ファイルでもテーマと配色を管理しやすい |
| データ可視化 | SVG + Vanilla JS | ドーナツチャートと株価チャートを軽量に描画 |
| データ | `kpi.json` / `segments.json` / `metadata.json` / `stock.json` | 表示データを HTML から分離して更新しやすくする |
| ホスティング | GitHub Pages などの静的ホスティング | ビルド不要で公開可能 |

## 🗂 データソース

- [ソニーグループ IR 情報](https://www.sony.com/ja/SonyInfo/IR/) — 決算短信、有価証券報告書
- [J-Quants API](https://jpx-jquants.com/) — 株価・財務データ(JPX 公式)
- [Wikipedia / Wikidata API](https://www.wikidata.org/) — 歴史的プロダクト情報
- [TMDB API](https://www.themoviedb.org/) — ソニーピクチャーズ作品情報(計画中)

## 🚀 セットアップ

依存パッケージはありません。JSON を `fetch` で読み込むため、ローカルサーバー経由で確認してください。

```bash
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開くとアプリが表示されます。
